ملفات إصلاح إدخال القنوات والمجموعات:
- chatTarget.js: تطبيع موحد للمدخلات والتحقق من الجهة وصلاحيات البوت عبر Telegram Bot API.
- channelManager.js: استخدام الدالة المشتركة مع اشتراط أن تكون الجهة قناة، والتحقق من صلاحية نشر البوت وإشراف المستخدم.
- commands/messages.js: استخدام الدالة نفسها للاشتراك الإجباري واشتراك الدردشة (بما يشمل إعداد اشتراك الدردشة من داخل المجموعة).
- commands/callbacks.js: تحديث إرشادات الإدخال للأنظمة الثلاثة.
- test/chatTarget.test.js: اختبارات صيغ الروابط والمعرفات والدعوات الخاصة والصلاحيات وربط الأنظمة الثلاثة.

لم يتم تعديل أو حذف قاعدة البيانات أو بيانات المستخدمين.
ملاحظة: Telegram Bot API لا يوفّر طريقة لإثبات أن رابط دعوة خاص يخص Chat ID بعينه؛ يتم التحقق من Chat ID وإمكانية وصول البوت ورتبته بشكل مستقل، وتظهر للمستخدم ملاحظة واضحة عن رابط الدعوة.
