# مشروع نغنوغ 🐈‍⬛ — نسخة مطوّرة

## المتطلبات
- Node.js 18 أو أحدث (يفضّل إصدار LTS).
- توكن البوت من BotFather.
- رقم Telegram ID الخاص بالمالك.
- إضافة البوت إلى المجموعة ومنحه صلاحيات حذف الرسائل وتقييد الأعضاء وتثبيت الرسائل بحسب الميزات المستخدمة.

## التشغيل
1. فك ضغط الملف.
2. افتح مجلد `telegram-bot-main` في بيئة Node.js.
3. نفّذ `npm install`.
4. عيّن متغيري البيئة:
   - `TELEGRAM_BOT_TOKEN` = توكن البوت.
   - `BOT_OWNER_ID` = Telegram ID للمالك.
5. شغّل `npm start`.

لا تضع التوكن داخل ملفات JavaScript ولا ترسله في المحادثات.

## ملاحظات مهمة
- إعدادات الحماية والبيانات والنقاط تُحفظ في `bot_data.json` بجانب `index.js`. خذ نسخة احتياطية من هذا الملف قبل استبدال المشروع أو نقله.
- النقاط الجديدة تُحفظ منفصلة لكل مجموعة في `groupPoints`. يحتفظ النظام بحقل `points` القديم للتوافق، ولا يحذف بياناته.
- أمر `المسح جميع الرسائل` يحتاج تأكيداً، ويحاول حذف آخر 100 رسالة ضمن نطاق محدد؛ قد ترفض Telegram حذف بعض الرسائل.
- حماية الرسائل لا تستطيع حذف المخالفات إذا لم يكن البوت مشرفاً مع صلاحية حذف الرسائل.
- النبذة الشخصية Bio ليست متاحة عبر Telegram Bot API، لذلك لا يعرضها البوت كأنها معلومة معروفة.
- ملف `game.js` القديم بقي ضمن الحزمة لتفادي حذف ملف قد تستخدمه إعدادات خارجية؛ مسار الألعاب الجديد في `commands.js` ولا يستورده `index.js`.

## الاختبارات التي أُجريت هنا
- فحص صياغة ملفات JavaScript الخمسة بواسطة `node --check`، وقد نجحت.
- لم يُجر اختبار اتصال حي مع Telegram لأن توكن البوت غير متوفر، ولم تكن مكتبة `grammy` مثبتة في بيئة الفحص. بعد `npm install` اختبر البوت في مجموعة تجريبية أولاً.
